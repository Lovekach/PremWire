# Contributing

Use synthetic fixtures, temporary databases and mocked network clients. Do not
include real tokens, browser profiles, private channel IDs, operator logs or source
exports. Run the offline suite and secret scanner before submitting changes.

Keep production and experimental routes distinct. Changes to dedupe must preserve
independent events and genuine development stages, while maintaining suppression,
tombstones and exact delivery mappings. Never test with live posting credentials.

Discuss architecture changes before restoring visual subsystems, enabling optional
integrations or adding resident processes. Do not add mandatory entity registries
or source-lock gates to the basic text publication route.

Contribute only original code you can license under the project's MIT terms.
Third-party media, model weights and datasets require a separate rights review;
they are not covered by the project's license.
